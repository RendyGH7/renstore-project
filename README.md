# 🛍️ RENSTORE — Premium E-Commerce Platform

Platform E-Commerce Modern Fullstack yang dibangun dengan **Laravel 12 (REST API)**, **React 19 + TypeScript (Vite)**, **PostgreSQL 17**, dan **Tailwind CSS**.

## ⚡ Cara Menjalankan Aplikasi

### 1. Jalankan Backend (Laravel API)
```bash
cd backend
php artisan serve
# Server REST API aktif di: http://127.0.0.1:8000
```

### 2. Jalankan Frontend (React Vite)
```bash
cd frontend
npm run dev
# Aplikasi aktif di: http://localhost:5173
```
